# Lazy MiniMax H3 — beginner guide

This folder is **on your machine only** (not uploaded with the pack). Open the **Lazy Docs** node, set **Folder** to:

```text
local_minimax_h3
```

Then click the titles on the left to read each page.

## What you will learn

1. What the big “all-in-one” graph is doing in plain English  
2. How **subject** and **scene** files work (character + situation)  
3. How to plug in a **local LLM** (LM Studio, built-in Hugging Face models, or TextGenerate)  
4. **Prompt examples** you can copy and adapt  

## Before you start

You need:

- ComfyUI **0.30+** with MiniMax H3 support  
- This custom node pack (**Vsaan212-workflow-utilities**) installed  
- The MiniMax H3 model files downloaded (see the pack’s shipped `minimax_h3` docs if needed)  

You do **not** need to understand Python or Git to use this guide.
